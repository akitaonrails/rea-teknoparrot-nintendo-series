nintendo-launcher — F-Zero AX, the Mario Kart Arcade GP games and Luigi's Mansion Arcade

  nintendo-launcher                          open the window (games, settings, controls)
  nintendo-launcher --library <folder>       add a folder with your games (repeatable)
  nintendo-launcher --segaboot <file>        the Triforce test-menu program (segaboot.gcm), optional
  nintendo-launcher --list                   list the games found and their state
  nintendo-launcher --check [<game>]         check a game (or all) can start, without starting
  nintendo-launcher --play <game> [options]  start a game (fzax, mkgp2, mkdx, luigi)
  nintendo-launcher --set <game> <options>   save options for a game without starting it (also --game)

Options (saved in that game's settings):
  --look original|recommended|steam_deck  Look
  --render <WxH|native>                   Game render size
  --output <WxH>                          Output size (Linux helper)
  --upscaler fsr|nis|linear|nearest       Upscaler (Linux helper)
  --sharpness <0-20>                      Sharpness (Linux helper)
  --crt off|lottes                        CRT look (Linux helper)
  --fullscreen on|off                     Fullscreen (Linux helper)
  --deadzone <0.00-0.30>                  Dead zone

Test options for --play:
  --headless               run in an invisible display
  --no-input               no controller input
  --input-script <file>    timed inputs
  --seconds <n>            stop the game after n seconds

  nintendo-launcher --help                   this text
